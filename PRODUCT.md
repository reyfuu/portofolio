# Reyfuu — product context
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Primary: recruiters and engineering leads reviewing evidence of software work.
Secondary: potential collaborators and developers exploring repositories.
These audience priorities are working assumptions, not measured audience research.

## Product Purpose
A professional developer portfolio that connects real work to readable technical
context and a direct email conversation. Success means visitors can identify Reyfuu,
inspect relevant source code and find contact information without searching a long archive.

## Positioning
An evidence-led view of Reyfuu’s own public GitHub projects. Repository ownership,
forks, detected languages and dates remain explicit. No invented career history.

## Operating Context
Visitors scan on mobile or desktop, follow GitHub links and email the owner.
The owner maintains the source and refreshes a GitHub snapshot with a local script.

## Capabilities and Constraints
Next.js 16, React 19, TypeScript, Tailwind 3. GitHub API with local fallback,
search/category filters, project details, language summary, project history and optional CLI.
Email: audinathanael@gmail.com. No contact backend, tracking service or CMS required.
Employment history, résumé and production domain remain unprovided; do not fabricate them.

## Brand Commitments
Reyfuu; professional editorial dark identity, restrained teal accents, no emoji.
Direct first-person copy, no unsupported seniority, availability or performance claims.
User requested Impeccable, 21st.dev and UI/UX Pro Max as design inputs.

## Evidence on Hand
`src/data/github-snapshot.json`: 61 repositories as of 2026-09-27.
GitHub descriptions, dates, languages and fork flags are evidence; absent descriptions
are absent evidence. No supplied product screenshots, testimonials or client outcomes.

## Product Principles
- Lead with inspectable work.
- Distinguish repository history from employment.
- Keep exploration and contact straightforward.
- Remain useful when external APIs fail.

## Accessibility & Inclusion
WCAG AA text contrast, keyboard operation, native controls and reduced motion.
Support 375px through 1920px, long names and 200% text zoom.
